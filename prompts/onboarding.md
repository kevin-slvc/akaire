# 初回オンボーディング — サンプルで1周する

**対象読者: このリポジトリを読み込んだAIエージェント（Claude Code / Codex / Cursor など）。**

Akaireを初めて使う相手には、本番の前にサンプルでの練習を一度だけ案内する。
完了とは「赤を入れる → AIへコピーする → AIが直す → 再読み込みで済みになる」まで。

## 0. 一度だけ案内する

案内する前に、Akaireのルートに印があるか確認する。

```sh
test -f <akaireのルート>/.akaire-onboarded && echo あり || echo なし
```

印があれば練習の話題を出さず、本番へ進む。無い場合だけ次の1問を聞く。

> Akaireでのレビューは初めてですか。初めてなら、本番の前にサンプルで1周だけ
> 練習してもらえますか（5分程度）。使ったことがあるなら飛ばします。

飛ばすと言われた場合も、次回また聞かないようAkaireのルートへ印を残す。

```sh
echo "$(date +%F) skipped" > <akaireのルート>/.akaire-onboarded
```

練習した場合は、手順4の完了後に `done` を残す。

```sh
echo "$(date +%F) done" > <akaireのルート>/.akaire-onboarded
```

印は生成物のコピー先ではなく、`rv-layer.js` と `README.md` があるAkaireのルートへ置く。
もう一度練習したいと相手が希望した場合は、この印を削除してから案内する。

## 1. サンプルを開く

[`../examples/sample-review.html`](../examples/sample-review.html) をブラウザで直接開いてもらう。
ローカルファイル（`file://`）でよく、サーバーは不要。`data-rv-default="on"` があるため通常は
レビュー層が最初から出る。以前 `#rv-off` で明示的に止めたブラウザなどで出ない場合は、
URL末尾に `#rv` を付けて開く。

左下の案内が出たら、実際に操作しながら進める。以前閉じていて案内が出ない場合だけ、
ブラウザのコンソールで `window.__rv.guide()` を実行すると再表示できる。

## 2. 欠陥へ赤を入れる

次のように伝える。1件だけでも一往復を試せる。3種類の指定方法を練習する場合は3件すべてへ
コメントしてもらう。答えは先に見せず、詰まったときだけ表をヒントとして使う。

> このページには意図的な欠陥が3つあります。本文、表、図から気になる箇所を選び、
> コメントを入れてください。終わったら右下の〈コピー〉を押し、内容をここへ貼ってください。

| 場所 | 欠陥 | 指定のしかた |
|---|---|---|
| 「背景」の本文 | 「月あたり約12時間」が表の合計14.5時間と合わない | 文字をドラッグして選ぶ |
| 「現状の内訳」の表 | 「1回あたり」列の単位が分と時間で混在 | 〈枠〉を押して表をクリック |
| 推移の棒グラフ | 縦軸が7.4から始まり、差が実際より大きく見える | Option（Windows / LinuxはAlt）を押しながらドラッグ。〈枠〉を押してからドラッグでもよい |

## 3. コピーされた赤入れを反映する

貼られたコメントだけを [`apply-review.md`](apply-review.md) の規約に沿って修正する。
コメントが1件なら、その指摘だけを直し、そのコメントIDだけを済みにする。

| 指摘 | 修正 |
|---|---|
| 本文の時間 | 「約12時間」を「約14.5時間」にする |
| 表の単位 | `0.05時間` を `3分` にする |
| グラフの縦軸 | 0から始まるよう `viewBox`、目盛り、棒の座標を引き直す |

修正後、`</body>` の直前へ、実際に対応したコメントIDだけを埋め込む。

```html
<script>window.__rvResolved={rev:"r20260906153045",ids:["<対応したコメントのID>"]}</script>
```

`rev` は秒まで含む対応時刻などを使って毎回変える。`ids` は表示番号ではなく、コピー文の
`(id:...)` にあるコメントIDを使う。正本は
[`../specs/resolved-contract.md`](../specs/resolved-contract.md)。

## 4. 修正を確認する

保存後、同じHTMLを再読み込みしてもらう。対応した指摘だけが「済み」へ移り、本文の印が
消えれば完了。右下の済み数から一覧を開き、〈戻す〉で未済みに戻せる。

ここで手順0の `done` の印を残す。練習後にサンプルを元へ戻す場合は、作業中の変更を確認してから
`git restore examples/sample-review.html` を実行する。ブラウザに残ったコメントは〈消去〉で消せる。
