# 手動テストチェックリスト

`rv-layer.js` は自動テストを持たない（DOM選択・座標・IndexedDB・zip生成が絡むため、
実ブラウザでの目視確認が最も確実）。リリース前・大きな変更後に以下を実機（Chrome/Safari/
Firefoxのいずれか、可能なら2つ以上）で確認する。

## 準備

各fixtureは `tests/fixtures/` 直下にあり、`../../rv-layer.js`（リポジトリルートの
`rv-layer.js`）を読み込む。ブラウザで直接ファイルを開くか、簡易サーバーで配信する。

```
cd html-review-loop
python3 -m http.server 8000
# http://localhost:8000/tests/fixtures/repeated-wraps.html#rv を開く
```

## 基本動作

- [ ] `#rv` を付けずに開くと、バー（右下の丸いUI）が出ない
- [ ] `#rv` を付けて開くと、バーが出る
- [ ] `#rv-off` を付けて開くと、バーが出ない（一度 `#rv` で有効化した後でも）
- [ ] `#rv` で開いた後、URLの `#rv` が自動で消える（`history.replaceState`）
- [ ] `?rv=1#section-x` のようにアンカー付きで開くと、`?rv=1` だけ消えて
      `#section-x` は残る（ページ内の行き先が失われない）
- [ ] 本文をドラッグ選択すると、選択範囲の下にコメント入力欄が開く
- [ ] コメントを保存すると、選択箇所に薄いハイライトと番号が付く
- [ ] リロードしてもコメントが残っている（`localStorage` 永続化）
- [ ] コメント件数がバーに表示される（「コメント N件」）

## 枠コメント（〔枠〕）

- [ ] バーの「枠」ボタンを押すと枠選択モードに入る（カーソルが十字になる）
- [ ] 表・カード・図などをクリックすると、その要素を囲む枠線とバッジが出る
- [ ] ↑↓キーで枠の粒度（外側/内側）を変えられる
- [ ] Option+クリックでも、ボタンを押さず一時的に枠選択モードへ入れる
- [ ] Escで枠選択モードを抜けられる

## 切り取り（〔切り取り〕）

- [ ] 枠選択モード中にドラッグすると、矩形選択（写真のトリミングのような見た目）になる
- [ ] ドラッグを離すとコメント入力欄が開く
- [ ] 保存後、リロードしても同じ位置に枠が復元される

## 対象ページとの干渉

- [ ] `* { box-sizing: border-box }` を**敷いていない**ページで、コメント入力欄が
      ポップアップの枠からはみ出さない
- [ ] レイヤーを載せても、対象ページ側の要素の `box-sizing` が変わらない
- [ ] バー・未照合の箱・済みパネルが、横にはみ出さない

## 保存の守り

- [ ] 同じページを2つのタブで開き、それぞれで別のコメントを保存する。
      あとから保存した側で、もう一方のタブのコメントが消えていない
- [ ] コメントを削除してからリロードしても、削除したコメントが復活しない
- [ ] 同じページに素早く2件コメントを付けても、2件とも別々に編集・削除できる（ID衝突なし）
- [ ] 画像を5枚まとめてドロップすると4枚で止まる

## 書きかけを失わない

- [ ] コメントを書きかけでEscを押すと「書きかけがあります。もう一度操作すると破棄します」と出て、消えない
- [ ] 書きかけのまま本文をクリックしても、1回目は同じ警告が出て閉じない（2回目で閉じる）
- [ ] 書きかけのまま別のコメントへ切り替えようとしても、1回目は閉じない
- [ ] 続けてもう一度Escを押すと閉じる
- [ ] コメントを書きかけのままページ内のリンクを踏むと、ブラウザの確認が出る
- [ ] 書きかけが無いときは、リンクを踏んでも確認が出ない

## 済み消し込み

- [ ] `__rvResolved` のタグは1つだけにする（2つ置くと後のタグが前を上書きし、
      先のタグのIDは処理されない。前回分は `ids` の和集合にまとめる）
- [ ] コメントを2〜3件付けた状態で、`</body>` 直前に
      `<script>window.__rvResolved={rev:"rtest1",ids:["<実際のid>"]}</script>`
      を手で埋め込んでリロードすると、該当コメントだけ「済み」になる
- [ ] 同じ `rev`（`rtest1`）で再度開いても、二重適用によるトースト再表示が起きない
- [ ] バーの「済み」ボタンで済み一覧パネルが開く
- [ ] 「戻す」を押すと該当コメントが再び未済みへ戻る

## 画像添付

- [ ] コメント入力欄が開いている状態で画像をペーストすると添付される
- [ ] ドラッグ&ドロップでも添付できる
- [ ] 5枚目を添付しようとすると「画像は4枚までです」と出て弾かれる
- [ ] 保存すると、原寸がダウンロードフォルダに書き出される

## 書き出し（zip）

- [ ] 未済みコメントが0件のときに「書き出し」を押すと「未済みコメントはありません」
- [ ] 未済みコメントがある状態で書き出すと、`rv-<slug>-<日時>.zip` がダウンロードされる
- [ ] zipを展開すると `review.md` と `source/`（元HTML）と `images/` が入っている
- [ ] `source/` の中身が、いま画面で見ていたHTMLと同じ内容である
- [ ] `review.md` の「元HTMLの取得経路」が、実際に使われた経路と合っている
      （サーバー配信なら fetch、`file://` なら DOMシリアライズ）
- [ ] `review.md` の `- 添付:` のパスと `images/` 内の実ファイル名が一致する
- [ ] コメントに「追記」を足してから書き出すと、`review.md` に `- 追記:` として出る
- [ ] 添付した画像形式（PNG/JPEG/WebP/GIF等）ごとに、zip内の拡張子が実際の形式と
      一致している（`tests/fixtures/image-formats.html` 参照）

## fixture別の確認（各ファイル冒頭コメントも参照）

- [ ] `repeated-wraps.html`: 3セクションとも選択でコメント欄が開く
- [ ] `duplicate-text.html`: 2件目・3件目に付けたコメントが、リロード後も同じカードに残る
- [ ] `nested-scroller.html`: 内側スクロール後も枠コメントの位置がアイテムに追従する
- [ ] `image-formats.html`: 複数形式の画像添付→書き出しで拡張子が正しく決まる
- [ ] `xss.html`: 位置を見失ったコメントの一覧に、タグに見える引用文が
      HTMLとして解釈されず、そのままの文字列として表示される

## 名前衝突

- [ ] 予約ID（例: `rvbar`）を持つ要素があるページを開くと、レビュー層は起動を中止し、
      画面上部に衝突を知らせるバナーが出る（コンソール警告だけでなく画面表示もされる）
- [ ] バナーの×ボタンで閉じられる

## 既知の未検証事項（このチェックリストの範囲外）

- 容量超過で原寸もサムネイルも失われたケース（`omitted` 経路）
- IndexedDBの権限が拒否された環境
- AVIF/SVG添付時のブラウザ別デコード挙動
- `iframe` 内コンテンツへの注釈（対応対象外。親ページのレビュー層には届かない）
- `body` に `transform` がかかっている場合の枠位置ズレ
